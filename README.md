# SmartNet VPN Android Source Code

این پروژه شامل سورس‌کد کامل اپلیکیشن اندروید **SmartNet VPN** به همراه اسکریپت ساخت خودکار فایل نصبی (**GitHub Actions**) است.

## مراحل دریافت فایل نصبی (APK) از طریق مرورگر گوشی:
1. وارد سایت [github.com](https://github.com) شوید و وارد حساب کاربری خود شوید.
2. یک مخزن (Repository) جدید بسازید (مثلاً با نام `SmartNetVPN`).
3. تمام فایل‌ها و پوشه‌های داخل این ZIP (به‌ویژه پوشه `.github` و `app`) را در مخزن آپلود کنید.
4. به تب **Actions** در بالای صفحه مخزن بروید؛ خواهید دید که فرآیند `Build Android APK` به‌صورت خودکار شروع شده است.
5. پس از سبز شدن تیک (حدود ۲ تا ۳ دقیقه)، روی آن کلیک کرده و از بخش **Artifacts** فایل `SmartNetVPN-APK` را دانلود و روی گوشی خود نصب کنید.
